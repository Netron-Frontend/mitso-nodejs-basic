# InsideOut CLI Tool

CLI инструмент для преобразования строк по правилу "выворачивания слов наизнанку" (задача №2).

## Описание задачи

Инструмент преобразует каждое слово в строке, выворачивая его "наизнанку":
- Внутренние буквы двигаются наружу, внешние - к центру
- Если слово четной длины, все буквы перемещаются
- Если слово нечетной длины, средняя буква остается на месте

### Примеры:
'taxi' → 'atix'
'taxis' → 'atxis'
'man i need a taxi up to ubud' → 'man i ende a atix up to budu'
